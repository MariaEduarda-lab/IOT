# Semana 08 — Sistema de disparo de atuadores

## Objetivos

- Acionar atuadores com segurança usando o ESP32 e módulos relé.
- Controlar atuadores remotamente por MQTT.
- Integrar entradas, sensores, atuadores e interface de usuário.
- Planejar e executar testes de integração em C++.

## Assuntos

- Módulos relé com ESP32.
- Utilização de atuadores.
- Acionamento de atuadores via Eclipse Mosquitto.
- Integração entre entradas, sensores, atuadores e interface de usuário.
- Testes de integração em C++.

## Materiais e referências

- [Eclipse Mosquitto](https://mosquitto.org/)
- [Documentação do ESP32](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/)
