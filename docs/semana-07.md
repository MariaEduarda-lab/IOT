# Semana 07 — Transmissão de sinal e dashboards

## Objetivos

- Avaliar a intensidade e a propagação de sinais Wi-Fi.
- Enviar dados do microcontrolador a uma plataforma IoT.
- Construir dashboards para acompanhar medições.

## Assuntos

- Mapa de calor da intensidade do sinal Wi-Fi em dBm.
- Antenas e propagação.
- Adafruit IO com Arduino IDE.
- Ubidots.
- Visualização de dados em dashboards.

## Materiais e referências

- [Adafruit IO](https://io.adafruit.com/)
- [Referência da API do Adafruit IO](https://io.adafruit.com/api/docs/)
- [Ubidots](https://ubidots.com/)
