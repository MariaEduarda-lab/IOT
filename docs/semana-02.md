# Semana 02 — Programação básica usada em microcontroladores

## Objetivos

- Consolidar os fundamentos de programação necessários para microcontroladores.
- Compreender como funções, texto, memória e operações matemáticas aparecem em sistemas embarcados.
- Introduzir controladores lógicos programáveis e diferenciá-los de microcontroladores.

## Assuntos

- Fundamentos de controladores lógicos programáveis (CLPs).
- Microcontroladores.
- Programação de microcontroladores.
- Funções.
- Strings e caracteres.
- Organização e uso da memória.
- Operações e funções matemáticas.
