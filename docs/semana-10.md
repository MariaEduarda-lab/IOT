# Semana 10 — Revisão final do projeto

## Objetivos

- Revisar a integração completa do projeto IoT.
- Identificar e corrigir falhas de hardware, software e comunicação.
- Verificar os requisitos e preparar a entrega final.

## Assuntos

- Revisão da arquitetura da solução.
- Sensores, processamento e atuadores.
- Comunicação e dashboards.
- Segurança e tratamento de credenciais.
- Testes, documentação e apresentação.

## Checklist de revisão

- [ ] O circuito está documentado e usa os pinos corretos.
- [ ] Sensores e atuadores funcionam de forma consistente.
- [ ] A comunicação se recupera de falhas previsíveis.
- [ ] O dashboard apresenta as informações necessárias.
- [ ] Credenciais e dados sensíveis não estão no repositório.
- [ ] Os principais fluxos possuem testes ou evidências de validação.
- [ ] O README do projeto explica instalação, configuração e uso.
- [ ] A demonstração final foi ensaiada.

## Lista de exercícios

> A lista será desenvolvida durante a preparação desta semana.

- [ ] Revisão cruzada entre projetos.
- [ ] Teste de ponta a ponta.
- [ ] Correção dos problemas encontrados.
- [ ] Simulação da apresentação final.
